# 紬の英会話レッスン

やさしく、楽しく、英語で話そう。AI会話パートナーと一緒に、日常会話からビジネス英語まで。

## 概要

このアプリは、日本人学習者が英語のスピーキング力を向上させるための会話練習ツールです。やさしく穏やかなAI会話パートナー「紬」と一緒に、自然な英会話を通じて学習できます。

### 主な機能

- 💬 **自然な会話練習**: フリートークから特定のシナリオまで、様々な場面で英語を練習
- 📝 **優しい訂正カード**: 間違いを見つけたら、日本語で分かりやすく説明
- 🎯 **8つの練習モード**: 
  - フリートーク
  - 日常会話
  - 旅行
  - 職場雑談
  - 会議
  - メール
  - プレゼンテーション
  - 語彙練習
- 📊 **学習進捗管理**: セッション履歴と上達度を記録
- 🎤 **音声入力対応**: ブラウザの音声認識で実際に話して練習（オプション）
- 💾 **自動保存**: 会話履歴と進捗をブラウザに保存

### レベル対応

- 初級（A2）: 日常会話レベル
- 中級（B1-B2）: 一般的な話題に対応
- ビジネス: 会議・プレゼン・メール対応

## セットアップ

### 1. 依存関係のインストール

```bash
npm install
```

### 2. 環境変数の設定（オプション）

OpenAI互換のLLM APIを使用する場合は、`.env.local`ファイルを作成してください：

```env
OPENAI_API_KEY=your_api_key_here
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini
```

**注意**: API キーなしでも、シンプルなモック応答で動作します。

### 3. 開発サーバーの起動

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。

## 本番ビルド

```bash
npm run build
npm start
```

## 技術スタック

- **フレームワーク**: Next.js 16 (App Router)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **状態管理**: React Hooks + localStorage
- **AI API**: OpenAI互換API（任意）

## 使い方

1. **モードを選択**: 右側のパネルから練習したいモードを選択
2. **会話を開始**: 紬が英語で話しかけてくるので、英語で返信
3. **訂正を確認**: 間違いがあれば、優しく訂正カードが表示されます
4. **セッション終了**: 練習が終わったら「セッション終了」ボタンで統計を確認

### 音声機能（オプション）

- ブラウザが音声認識に対応している場合、「音声ON」ボタンが表示されます
- 「話す」ボタンをクリックして、実際に英語を話して練習できます
- 紬の返答も音声で読み上げられます
