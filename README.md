# つむぎ英会話 🌸

**Tsumugi English Conversation** - スマホで気軽に英会話練習！

ファン創作の英会話練習アプリです。つむぎと一緒に、自然な英語の会話を練習しましょう。

> ⚠️ **免責事項**: このアプリは個人が制作したファン作品です。Summer Pocketsやつむぎのキャラクター、公式アートワークなどは一切使用していません。

## ✨ 主な機能

### 📱 スマホ対応
- **モバイルファースト設計**: 小さい画面でも快適に使える UI
- **PWA対応**: ホーム画面に追加してアプリのように使える
- **安全エリア対応**: iPhone のノッチにも対応

### 🎤 音声会話モード
- **タップして話す**: マイクボタンをタップして英語で話しかけられます
- **自動音声返答**: つむぎの返事を自動で読み上げ（ミュート可能）
- **Web Speech API**: iOS Safari、Android Chrome に対応

### 💬 優しい添削
- 文法や表現のミスを優しく訂正
- 訂正内容は自動で復習リストに追加

### 📚 復習モード
- 訂正された表現をカード形式で復習
- 繰り返し学習で定着をサポート

### 💼 ビジネスシナリオ
- 会議、プレゼン、交渉などのシーン別練習
- 実践的なビジネス英語をロールプレイで学習

## 🚀 使い方

### スマホにインストール（推奨）

#### iPhone / iPad (Safari)
1. Safari でアプリを開く
2. 画面下の共有ボタン（□↑）をタップ
3. 「ホーム画面に追加」を選択
4. 「追加」をタップ

#### Android (Chrome)
1. Chrome でアプリを開く
2. 右上のメニュー（⋮）をタップ
3. 「ホーム画面に追加」または「アプリをインストール」を選択
4. 「追加」をタップ

### 音声機能の使い方

1. **マイク許可**: 初回使用時、マイクへのアクセス許可が必要です
2. **話す**: 🎤 ボタンをタップして英語で話す
3. **自動停止**: 話し終わると自動で認識が止まります
4. **音声ミュート**: 右上の 🔊 ボタンでつむぎの音声を ON/OFF

#### iOS Safari の制限について
- iOS Safari では音声認識が制限される場合があります
- その場合はテキスト入力でもご利用いただけます

### モード切り替え

- **💬 おしゃべり**: フリートーク。何でも話せます
- **📚 復習**: これまでの訂正を復習
- **💼 ビジネス**: シナリオ別のビジネス英語練習

## 🛠️ 開発

### セットアップ

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev
```

開発サーバーは http://localhost:3000 で起動します。

### ビルド

```bash
# プロダクションビルド
npm run build

# プロダクションサーバーの起動
npm start
```

### 技術スタック

- **Next.js 14** - React フレームワーク
- **TypeScript** - 型安全な開発
- **Tailwind CSS** - モバイルファーストな UI
- **Web Speech API** - 音声認識・音声合成
- **PWA** - オフライン対応とホーム画面追加
