# 紬の英会話レッスン 🌸

やさしく、楽しく、英語で話そう。AI会話パートナーと一緒に、日常会話からビジネス英語まで。

**スマホ対応 PWA** - ホーム画面に追加してアプリのように使えます！

## 概要

このアプリは、日本人学習者が英語のスピーキング力を向上させるための会話練習ツールです。やさしく穏やかなAI会話パートナー「紬」と一緒に、自然な英会話を通じて学習できます。

### 主な機能

- 💬 **自然な会話練習**: フリートークから特定のシナリオまで、様々な場面で英語を練習
- 📝 **優しい訂正カード**: 間違いを見つけたら、日本語で分かりやすく説明
- 📚 **復習リスト**: 間違えた表現を自動保存し、後でまとめて復習・ドリル練習
- 🎯 **練習モード**: 
  - フリートーク
  - 日常会話
  - 旅行
  - 職場雑談
  - **💼 ビジネス英語（拡張版）**
- 💼 **充実したビジネス英語練習**:
  - 📊 **会議の基本**: アジェンダ確認、丁寧な反対意見、明確化の依頼、アクションアイテムのまとめ
  - 📧 **メールトーン調整**: カジュアルな英語をプロフェッショナルなメール英語に書き換え
  - 🎤 **プレゼンQ&A**: 厳しい質問への対応、時間稼ぎフレーズ、数字の明確化
  - ☕ **職場での雑談**: コーヒーチャット、新チームへの参加、週末から仕事への移行
  - 🤝 **交渉・スケジュール調整**: 時間の提案、丁寧な押し返し、次のステップの確認
  - 📞 **電話・ビデオ会議**: 接続確認、発言のターン取り、聞き返し
  - 📖 **フレーズバンク**: 各シナリオで使える表現を6-10個表示、クリックで入力可能
  - 🌱 **段階的難易度調整**: 初級→中級→上級、成功すると自動レベルアップ
  - 💡 **セッションヒント**: おすすめフレーズを3つ提案
- 📊 **学習進捗管理**: セッション履歴と上達度を記録
- 🎤 **音声入力対応**: ブラウザの音声認識で実際に話して練習（オプション）
- 💾 **自動保存**: 会話履歴と進捗をブラウザに保存

### 📱 スマホ対応・PWA機能

- **モバイルファースト設計**: 小さい画面でも快適に使える UI
- **PWA対応**: ホーム画面に追加してアプリのように使える
- **安全エリア対応**: iPhone のノッチにも対応
- **オフライン対応**: 基本機能はオフラインでも動作

### レベル対応

- 初級（A2）: 日常会話レベル
- 中級（B1-B2）: 一般的な話題に対応
- ビジネス: 会議・プレゼン・メール対応

## 🚀 スマホにインストール（推奨）

このアプリはPWA（Progressive Web App）対応です。ホーム画面に追加すると、ネイティブアプリのように使えます。

### ✨ インストールのメリット

- 📱 ホーム画面からワンタップで起動
- 🔌 オフラインでも基本機能が使える
- 🎯 全画面で没入感のある学習体験
- 🎤 音声機能がスムーズに動作
- 🚀 高速起動

### iPhone / iPad (Safari)

1. **Safari** でアプリを開く（Chrome等では追加できません）
2. 画面下の**共有ボタン**（□↑）をタップ
3. 下にスクロールして**「ホーム画面に追加」**を選択
4. 右上の**「追加」**をタップ

### Android (Chrome)

1. **Chrome** でアプリを開く
2. 右上の**メニュー**（⋮）をタップ
3. **「ホーム画面に追加」**または**「アプリをインストール」**を選択
4. **「追加」**または**「インストール」**をタップ

### 📱 別のデバイスからアクセス

アプリ内の **QRコードボタン**（右下）をクリックすると、スマホでスキャンしてアクセスできます。

### ⚠️ 重要な注意事項

- **HTTPS環境が必須**: PWAインストールと音声機能は、HTTPS環境（Vercel、Netlify等）でデプロイした場合のみフル機能します
- **localhost**: 開発環境（`http://localhost:3000`）ではPWAインストールと音声機能に制限があります
- **推奨デプロイ先**: Vercel（[vercel.com](https://vercel.com)）で簡単にデプロイできます

## セットアップ

### 1. 依存関係のインストール

```bash
npm install
```

### 2. 環境変数の設定（オプション）

このアプリは **AI佐藤さんと同じDeepSeek接続** を使用します。

OpenAI互換のLLM API（DeepSeek推奨）を使用する場合は、`.env.local`ファイルを作成してください：

```env
OPENAI_API_KEY=your_deepseek_api_key_here
OPENAI_BASE_URL=https://api.deepseek.com
OPENAI_MODEL=deepseek-v4-flash
```

- **DeepSeek API Key**: [https://platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys) で取得
- **互換性**: OpenAI互換APIなら他のプロバイダーも使用可能
- **モックモード**: API キーなしでも、シンプルなモック応答で動作します

**⚠️ 重要**: API キーは `.env.local` にのみ記載し、Gitにコミットしないでください。

### 3. 開発サーバーの起動

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。

## 本番ビルド・デプロイ

### Vercelへのデプロイ（推奨）

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/USHIKUNDESUYO/tsumugi-eikaiwa)

1. 上のボタンをクリック、またはVercelにGitHubリポジトリを接続
2. 環境変数を設定:
   - `OPENAI_API_KEY`: DeepSeek APIキー
   - `OPENAI_BASE_URL`: `https://api.deepseek.com`（デフォルトで設定済み）
   - `OPENAI_MODEL`: `deepseek-v4-flash`（デフォルトで設定済み）
3. デプロイ完了！HTTPS URLでPWA機能と音声機能がフル動作します

### ローカルで本番ビルド

```bash
npm run build
npm start
```

**注意**: ローカルビルドではHTTPSではないため、PWAインストールと音声機能に制限があります。

## 使い方

1. **モードを選択**: 右側のパネルから練習したいモードを選択
2. **会話を開始**: 紬が英語で話しかけてくるので、英語で返信
3. **訂正を確認**: 間違いがあれば、優しく訂正カードが表示されます
4. **復習リストで復習**: 「復習リスト」タブで間違えた表現をまとめて確認・ドリル練習
5. **セッション終了**: 練習が終わったら「セッション終了」ボタンで統計を確認

### 音声機能（オプション）

- ブラウザが音声認識に対応している場合、「音声ON」ボタンが表示されます
- 「話す」ボタンをタップして、実際に英語を話して練習できます
- 紬の返答も音声で読み上げられます
- **スマホでの音声機能**: タップして話す形式で、モバイルに最適化されています

#### 📱 スマホ音声機能の注意事項

**iOS Safari での利用**:
- ✅ 音声認識は対応していますが、タップごとに1回の発話が必要です
- ✅ 初回は必ずマイクの許可を求められます（「許可」を選択してください）
- ⚠️ ブラウザの設定で「マイクへのアクセス」が許可されていることを確認してください
- ⚠️ プライベートブラウジングモードでは音声機能が制限される場合があります
- 💡 音声が利用できない場合でも、テキスト入力で完全にご利用いただけます

**HTTPS環境が必須**:
- 🔒 音声認識機能は、HTTPS接続（Vercel、Netlify等）でのみ動作します
- localhost開発環境では音声機能に制限があります

### 復習リスト機能

- 会話中に訂正された表現は自動的に復習リストに保存されます
- 「復習リスト」タブで保存された間違いを一覧表示
- 「復習する」ボタンでドリル練習モードに入り、正しい表現を練習
- 習得済みマークや削除で復習リストを管理できます

### ビジネス英語機能（A2→ビジネスレベル学習者向け）

**充実した6つのビジネスシナリオ**で、実践的なビジネス英語を段階的に学習できます：

#### 各シナリオの特徴
- **会議の基本**: 議題確認から意見の対立、要約まで実践的な会議英語
- **メールトーン調整**: カジュアルな表現をプロフェッショナルに書き換える練習
- **プレゼンQ&A**: 質問対応、時間稼ぎ、不明点への対処を学習
- **職場での雑談**: スモールトークから仕事の話題への自然な移行
- **交渉・スケジュール調整**: 提案、断り方、調整の実践
- **電話・ビデオ会議**: 技術的問題への対処、発言のタイミング

#### A2学習者向けスキャフォールディング
- 初級・中級・上級の3段階難易度
- 成功すると自動的に難易度がアップ
- 各レベルで適切な語彙と表現を使用

#### 学習サポート機能
- **フレーズバンク**: 各シナリオで使える表現を6-10個表示
- クリックして入力欄に挿入可能
- 日本語訳付きで意味を確認
- **セッションヒント**: 練習すると良いフレーズを3つ提案
